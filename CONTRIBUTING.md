## 🛠️ How to Play with Mods

Want to spice up your game? This package supports mods out of the box.

1. **Find mods** — Browse sites like CurseForge or Planet Minecraft for Java Edition mods.
2. **Download mods** — Get `.jar` files (make sure they match your Minecraft version).
3. **Open the mods folder** — Inside your extracted game directory, look for a folder named `mods`. If it doesn’t exist, create one.
4. **Drag and drop** — Move your downloaded `.jar` mod files into the `mods` folder.
5. **Launch the game** — Start the game normally, and your mods will load automatically.

Popular modpacks like *All the Mods 11* work by dropping the entire modpack folder into the `mods` directory. Data packs and resource packs follow the same simple process.
